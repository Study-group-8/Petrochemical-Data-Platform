# Petrochemical Data Platform 🏭

[![Go Version](https://img.shields.io/badge/Go-1.24-blue.svg)](https://golang.org)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![Docker](https://img.shields.io/badge/Docker-ready-brightgreen.svg)](docker-compose.yml)
[![GitHub Pages](https://img.shields.io/badge/demo-live-success.svg)](https://study-group-8.github.io/Petrochemical-Data-Platform/)

Современная платформа для мониторинга и анализа рынка нефтехимической продукции в России. Система обеспечивает сбор, хранение и визуализацию данных о ценах, объемах продаж и выручке от ведущих производителей отрасли.

## 🌐 Live Demo

**🚀 [Попробовать прямо сейчас](https://study-group-8.github.io/Petrochemical-Data-Platform/)**

Демо версия работает с синтетическими данными и не требует установки backend сервисов.

## 🎯 Основные возможности

- **23 крупнейших компании**: СИБУР, Роснефть, Газпромнефть, Лукойл, Новатэк, Татнефть и др.
- **36+ продуктов**: Полипропилен, Полиэтилен, СПГ, Нефтепродукты, Каучуки, Химикаты
- **Аналитика в реальном времени**: Мониторинг цен, объемов и выручки
- **Гибкие временные периоды**: От 6 месяцев до 10 лет + произвольный выбор дат
- **3 типа графиков**: Динамика цен, Объемы продаж, Выручка
- **Интерактивный календарь**: Выбор произвольного периода анализа
- **REST API**: Полнофункциональный API для интеграции
- **Веб-интерфейс**: Интерактивные графики с Chart.js и аналитика

### Компоненты системы

- **Data Generation**: Симулятор генерирует реалистичные данные для 36+ продуктов
- **Storage Layer**: PostgreSQL (компании), ClickHouse (временные ряды цен/объемов), Redis (кеширование)
- **Business Logic**: REST API на Gin, бизнес-логика на Go
- **Simulation**: Генератор данных с трендами роста/падения для долгосрочного анализа
- **Frontend**: Интерактивный веб-интерфейс с графиками Chart.js, календарём выбора периода

#### Установка и запуск

1. **Клонировать репозиторий**
```bash
git clone https://github.com/Study-group-8/Petrochemical-Data-Platform.git
cd Petrochemical-Data-Platform
```

2. **Запустить все сервисы**
```bash
docker compose up -d
```

3. **Запустить фронтенд**
```bash
cd frontend
python3 -m http.server 3000
```

4. **Открыть в браузере**
- Фронтенд: http://localhost:3000
- API: http://localhost:8080
- ClickHouse: http://localhost:8124

## 📊 Использование веб-интерфейса

### Основные функции

1. **Выбор компании**
   - Список из 23 компаний с фильтрацией
   - Поиск по названию компании или продукту
   - Фильтры по размеру (Крупная/Средняя/Малая) и типу (Производитель/Дистрибьютор)

2. **Выбор продукта**
   - Кнопки переключения между продуктами компании
   - Автоматическое обновление всех графиков

3. **Выбор временного периода**
   - **Предустановленные**: 6 месяцев, 1 год, 2 года, 3 года, 5 лет, 10 лет
   - **Произвольный период**: Календарь для выбора любых дат
   - Показывает количество точек данных

4. **Три типа графиков**
   - 📈 **Динамика цен** - Линейный график изменения цены во времени
   - 📊 **Объемы продаж** - Столбчатая диаграмма объемов производства
   - 💰 **Выручка** - График выручки (цена × объем) с автоматическим расчётом

5. **Статистика**
   - Средняя цена за период
   - Средний объем продаж
   - Средняя выручка
   - Период данных

6. **Экспорт данных**
   - CSV экспорт с защитой паролем
   - Включает все данные по выбранному продукту

### Использование календаря (произвольный период)

1. Выберите компанию
2. В селекторе "Период данных" выберите **"📅 Свой период..."**
3. В модальном окне укажите:
   - **Начальную дату** (например, 01.01.2015)
   - **Конечную дату** (например, 14.11.2024)
4. Увидите предпросмотр:
   - "1 января 2015 г. — 14 ноября 2024 г."
   - "Период: 118 мес. (3605 дней) • ~118 точек данных"
5. Нажмите **"Применить период"**
6. Все графики обновятся с новыми данными

- **Docker**: Контейнеризация всех сервисов
- **Docker Compose**: Оркестрация multi-container приложений
- **MQTT (Mosquitto)**: Брокер сообщений (опционально)

### База данных

**ClickHouse** (телеметрия):
```sql
CREATE TABLE telemetry (
    company_id String,
    product_name String,
    value Float64,
    unit String,
    timestamp DateTime,
    quality UInt16
) ENGINE = MergeTree()
PARTITION BY toYYYYMM(timestamp)
ORDER BY (company_id, product_name, timestamp)
TTL timestamp + INTERVAL 90 DAY;
```

**PostgreSQL** (компании):
```sql
CREATE TABLE assets (
    id SERIAL PRIMARY KEY,
    company_id VARCHAR(100) UNIQUE NOT NULL,
    name VARCHAR(255) NOT NULL,
    type VARCHAR(50),
    location VARCHAR(255),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 🎨 Особенности UI

### Адаптивные графики
- Автоматическое прореживание меток на оси X для длинных периодов

- Валидация: начало < конца, максимум до текущей даты

### Три графика

3. **Выручка** - Линейный график с автоматическим расчётом (оранжевый цвет)
